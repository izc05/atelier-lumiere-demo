# Atelier Lumière · demostración pública

Prototipo navegable de una tienda de artículos artesanales para bodas, comuniones y celebraciones.

## Qué se puede probar

- Portada animada y responsive.
- Tienda con filtros por evento, categoría y proveedor.
- Fichas de producto con historia, plazos y solicitud personalizada.
- Carrito limitado a un solo proveedor para compartir el envío.
- Blog y acceso de cliente en modo demostración.

Esta rama contiene únicamente la exportación estática preparada para GitHub Pages. No incluye credenciales, pasarelas de pago, datos reales ni la configuración privada del servidor.
